# Test cases for Problem 5, written in plain arithmetic instead of nested
# constructors. The autograder parses the left side with the generated
# lexer and parser (lexer.mll / parser.mly) into a Hw1.expr, runs the
# student's eval on it, and compares with the right side.
#
# Format:   expression => expected      ("error" means eval returns None)
# Lines starting with # are comments. OCaml's ( / ) rounds toward zero.

(2 + 3) * 4          => 20
10 - 4 - 3           => 3
100 / 10 / 5         => 2
-7 / 2               => -3
7 / -2               => -3
2 * -3               => -6
- - 5                => 5
((((42))))           => 42
1 / (2 - 2)          => error
5 + 1 / 0 * 3        => error
(1 / 0) - (1 / 0)    => error
